# ZNS / Defense Force Food Demand Forecasting & Inventory Management System

A robust, military-grade institutional supply chain management and AI predictive analytics engine designed for defense mess hall logistics and perishability risk auditing.

## Architecture & Technology Stack
- **Database:** PostgreSQL 16 (Relational integrity, atomic inventory auditing, perishability countdowns)
- **Backend Core:** Python 3.10+, Flask, Psycopg2 (Tactical routing & live stock intake pipeline)
- **Machine Learning Engine:** Scikit-Learn (Ridge Regression), Joblib (Model serialization & feature scaling)
- **Frontend Interface:** HTML5, CSS3, Tactical Army-Green Design System (Responsive command dashboard)

## Core Phases Implemented
1. **Schema Design:** Relational normalization across suppliers, food commodities, inventory batches, operational headcounts, and AI demand logs.
2. **Perishability Risk Logic:** Real-time shelf-life calculation and priority sorting that elevates fast-expiring fresh produce over bulk stable stock.
3. **Machine Learning Pipeline:** Synthetic institutional operations training capturing headcount, weather variations, seasonal shifts, and training surges.
4. **Command Dashboard:** Real-time inventory risk auditing, personnel headcount tracking, and historical log expansion via translucent UI controls.
5. **System Hardening:** Environment variable security, automated historical data seeding (Aug–Nov 2026), and interactive live intake simulation.
